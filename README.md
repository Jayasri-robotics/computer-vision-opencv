# Computer Vision & OpenCV Projects

A collection of real-time Computer Vision applications developed using Python, OpenCV, and MediaPipe.

## Projects

### 1. Virtual Painting
A gesture-based virtual painting application that allows users to draw on a virtual canvas using hand movements.

**Technologies:** Python, OpenCV, MediaPipe, NumPy

### 2. Hand Tracking
A real-time hand tracking application that detects and visualizes 21 hand landmarks using a webcam.

**Technologies:** Python, OpenCV, MediaPipe, NumPy
