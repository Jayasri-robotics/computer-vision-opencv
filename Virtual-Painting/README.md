# Virtual Painting using Computer Vision

A real-time virtual painting application developed using Python, OpenCV, and MediaPipe.

## Features
- Real-time hand tracking
- Finger-based drawing
- Virtual color selection
- Interactive drawing canvas
- Clear canvas functionality

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Project Structure
```text
Virtual-Painting/
├── virtual_paint.py
├── hand_landmarker.task
├── requirements.txt
└── README.md
```

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python virtual_paint.py
```

## Controls
- Use your hand gestures to draw.
- Select colors using the color selection interface.
- Press `C` to clear the canvas.
- Press `Q` to quit the application.

## Learning Outcomes
- Real-time computer vision
- Hand landmark detection
- Gesture-based interaction
- Image processing using OpenCV
