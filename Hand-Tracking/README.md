# Real-Time Hand Tracking using Computer Vision

A real-time hand tracking application developed using Python, OpenCV, and MediaPipe.

## Features
- Real-time hand detection
- Hand landmark tracking
- 21 hand landmarks detection
- Live webcam visualization
- Smooth landmark visualization

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Project Structure
```text
Hand-Tracking/
├── hand_tracking.py
├── hand_landmarker.task
├── requirements.txt
└── README.md
```

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python hand_tracking.py
```

## Controls
- Press `Q` to quit the application.

- Real-time hand tracking
- Hand landmark detection
- Computer vision fundamentals
- Image processing using OpenCV
- MediaPipe integration
